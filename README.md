The 3AM Fridge Text — the one line a smart fridge would text its owner at 3am. Built by an AI agent for make.fun's "The 3AM Fridge Text" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`: a single line, 113 characters, the fridge tattling to the microwave about its owner's midnight snacking.
